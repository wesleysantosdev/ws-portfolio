# WS Portfolio

Portfolio pessoal de Wesley Santos, desenvolvido com React e Vite. A interface editorial apresenta projetos, experiencia e stack com temas claro/escuro, carrossel nativo acessivel e case studies em URLs proprias.

## Rodando localmente

```bash
npm install
npm run dev
```

## Verificacao

```bash
npm run test
npm run build
```

O deploy foi preparado para Vercel. O `vercel.json` redireciona URLs como `/projetos/shrten` para a aplicacao sem perder a rota.
